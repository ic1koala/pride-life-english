# 学習バッジシステム獲得ルール＆仕様書 (Learning Badge System Rules)

本ドキュメントは、**Pride Life English** オンラインアカデミーにおける「学習バッジコレクション（マイページ）」の獲得ルール、背景画像処理仕様、フロントエンドおよびバックエンドの設計仕様をまとめたリファレンスシートです。

---

## 🏆 1. バッジ一覧と取得条件 (Milestone Badges & Criteria)

本アカデミーは1期（6ヶ月間）ごとに自動更新されるサブスクリプション形態を採っており、2期（12ヶ月間・合計192レッスン）で全体のカリキュラムが完結します。それに紐づく形で以下の4つの限定バッジが贈られます。

| バッジID | バッジ名称 (表示名) | 獲得条件・トリガー | 学習動機（モチベーション）設計 |
| :--- | :--- | :--- | :--- |
| `term_1_complete` | **1st Half (前半戦完走)** | **96レッスン完了**<br>(第1学期の全レッスンを修了) | 最初にして最大のハードルである「最初の6ヶ月間」を完走した証。レインボー調のプライドグラデーションで特別感を演出。 |
| `term_2_complete` | **2nd Half (後半戦完走)** | **192レッスン完了**<br>(第2学期の全レッスンを修了) | 1年間の長期学習を最後まで諦めずにやり遂げた英雄の証。夕暮れを思わせるサンセットゴールド色。 |
| `course_complete` | **Complete (完全卒業)** | **192レッスン完了**（上記と連動）<br>(全192レッスン修了) | コース全体の完全踏破を称える卒業バッジ。本格的な英語力をその手に掴んだ自信を表すロイヤルエメラルド調。 |
| `master_badge` | **Master (究極の覇者)** | **192レッスン完了 ＋ 全タスククリア**<br>(全レッスン完了時に同時付与) | 授業の受講だけでなく、毎日の全てのデイリー課題やジャーナリング等を完璧に完遂した「究極のマスター」のみが得られる最高峰バッジ。 |

## 🎨 2. 画像アセット透明化仕様 (Transparency Processing)

元データ画像は固体の白色背景を含んでいたため、マイページの半透明ガラス（グラスモーフィズム）の背景と綺麗に調和させるために背景透過処理を行いました。

### 2-1. 透明化アルゴリズム（BFS Flood-fill）
単純な「白色（#FFF）をすべて透明にする」という手法では、ロゴやバッジの内側にあるテキストや白いデザインパーツまで透明に抜けてしまいます。そのため、**画像の四隅のピクセルを出発点とした「幅優先探索 (BFS) による近接白領域の塗りつぶし」**を採用しました。

* **処理基準**:
  - 対象アセット: `client/public/badges/badge_*.png`
  - 開始座標: `(0, 0)`, `(width-1, 0)`, `(0, height-1)`, `(width-1, height-1)`
  - 判定閾値: RGB値がすべて240以上のピクセルを「背景の白」とみなして探索（圧縮ノイズ対策）。
  - 結果: バッジ外面の白背景のみが完全に透明化（Alpha=0）され、内側の純白のデザインディテールは100%保護されました。

## 💻 3. フロントエンド表示仕様 (Frontend UX Rules)

未取得のバッジスロットを「早く埋めたい！」「毎日レッスンを進めたい！」と思わせるゲーミフィケーションデザインを実装しています。

### 3-1. 未獲得（Locked）状態の表示ルール
* **ビジュアル**: 
  - 画像はグレーのシルエット風（`filter grayscale opacity-30 contrast-75 brightness-[60%] blur-[0.2px]`）で表示。
  - スロット中央に南京錠の鍵アイコン（🔒）を配置。
* **進捗表示（進捗バー）**:
  - カードの下部には、それぞれのバッジに必要な完了レッスン数に対する現在の達成率を算出する**視覚的なプログレスゲージ（進捗バー）**を表示。
* **文言ルール（モチベーション喚起）**:
  - 1st Half: `あと [残りレッスン数] レッスンでアンロック！`
  - 2nd Half: 1stターム未完走時は `1stターム完走後に挑戦可能になります`、開始後は `あと [残りレッスン数] レッスンでアンロック！` と表示。
  - Complete / Master: それぞれのアンロックまでの距離を数字で明記。

### 3-2. 獲得済み（Unlocked）状態の表示ルール
* **ビジュアル**:
  - グレーが解け、カラフルなアセットが完全表示。
  - ホバー時にカード境界線が光り、背面から柔らかなグロー（ネオングラデーション）が浮き上がる演出。カードが少し浮き上がるホバーアクション（`hover:scale-[1.03] duration-500`）が発動。
* **ステータス表示**:
  - ステータスラベルを「`✓ 獲得済み`」へと変更（ピンク色のアクティブ文字）。
  - データベースに記録された正確な獲得日時を取得し、「`獲得日: 2026年5月30日`」のように日本語のフォーマットで右下に表示。

## ⚙️ 4. バックエンド獲得ロジック (Backend Integration)

### 4-1. データベーススキーマ (`drizzle/schema.ts`)
獲得履歴は `milestones` テーブルに永続化され、獲得日時（`earnedAt`）が自動記録されます。

```ts
export const milestones = mysqlTable("milestones", {
  id: int("id").autoincrement().primaryKey(),
  userId: int("userId").notNull(),
  badgeType: varchar("badgeType", { length: 64 }).notNull(), // 'term_1_complete' など
  badgeLabel: varchar("badgeLabel", { length: 128 }).notNull(),
  earnedAt: timestamp("earnedAt").defaultNow().notNull(),
});
```

### 4-2. 自動判定＆通知処理 (`server/routers.ts`)
レッスン完了時 (`progress.completeLesson`) に受講生の累計完了数がチェックされ、以下のタイミングで自動的にバッジが授与されます：
1. **累計96レッスン完了時**: `term_1_complete` を付与し、通知ボックスにメッセージを送信。
2. **累計192レッスン完了時**: 
   - `term_2_complete` を付与。
   - `course_complete` を同時付与。
   - `master_badge` を同時付与。
   - それぞれに対応する華やかなお祝い通知がユーザーの通知欄に配信されます。

## 📌 変更と拡張のガイドライン
バッジ条件の変更（例：課題提出数の完全連動や新イベントバッジの追加）の際は、必ず本仕様書および `rulebook.md` を更新した後に、`server/routers.ts` の判定マッピングおよび `client/src/pages/SettingsPage.tsx` の `BADGES` 配列を変更してください。
